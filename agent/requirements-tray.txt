# Backend für das Systray-Symbol unter Linux. pystray kann drei Wege nutzen:
# AppIndicator und GTK laufen über PyGObject (ein Systempaket, das sich nicht sinnvoll in
# eine einzelne Programmdatei bündeln lässt), python-xlib dagegen ist reines Python und
# landet direkt mit in der gebauten Datei -- damit funktioniert das Symbol auf allen
# Desktops mit klassischem X11-Tray (KDE, XFCE, MATE, Cinnamon).
# Auf GNOME/Wayland gibt es ohne AppIndicator-Erweiterung überhaupt keinen Tray; dort
# schaltet die App automatisch auf ihr Fenster um (siehe tray_app.choose_ui_mode).
python-xlib>=0.33; sys_platform == "linux"
